## 2. Definition bearbeiten und XDF-Export (fertig, getestet)

| Befund (vor der Änderung nachgewiesen) | Behebung |
|---|---|
| Geprüfte Definition blieb nach Adress-, Größen-, Typ-, Skalierungs- oder Achsenänderung „geprüft“ (nur Warnung) | Prüfstatus wird zurückgesetzt; nur ein ausdrücklicher Klick bestätigt ihn erneut |
| Gespeicherte Achsenadresse ließ sich im Dialog nicht entfernen (leeres Feld = „unverändert“) | Leeren entfernt Adresse und daraus gelesene Werte, mit Hinweis |

| Bericht konnte als TunerPro-Test missverstanden werden | sagt ausdrücklich: eigener Import, kein Test in TunerPro |

## 3. Lokale Referenzsuche beim Öffnen einer BIN (teilweise Phase 1, getestet)

- Neue indizierte Tabelle `identifiers` (Hardware-/Softwarenummern). Ältere Datenbanken bleiben für ältere Versionen
  lesbar; fehlende Einträge werden beim Öffnen aus gespeicherten Metadaten ergänzt, ohne BIN.
- Stufen: **nachgewiesen** (identische Datei), **wahrscheinlich** (gleiche SW-Nummer, mit/ohne HW), **mehrdeutig**
  (nur HW oder nur Familie). Gleiche Nummern schließen eine geänderte Datei nicht aus; das steht im Grund.
- Auswahl öffnet wie bisher erst Vorschau (Kennfeldpaket-Dialog bzw. Softwarestand-Vergleich); nichts wird
  automatisch übernommen, keine Firmwarebytes werden verändert.
- „Bestehende Projekte indexieren …“: Stapel mit Fortschritt, Abbruch und gesammelter Fehlerliste.

Benchmark (`python -m ecu_studio.tools.library_benchmark`, 20 000 Projekte + 2 000 Pakete, synthetisch, gleicher
Rechner, 15 Wiederholungen, Median):

| Messung | vorher | nachher |
|---|---:|---:|
| Datenbankanteil je indiziertem Projekt | 17,4 ms | 0,27 ms (Stapel) |
| Vorschläge beim Öffnen, Nummern bekannt | 25,5 ms (100 Treffer, nur Hash/Familie) | 28,2 ms (171 Treffer, davon 71 über Nummern) |
| Vorschläge beim Öffnen, Nummern unbekannt | 39,3 ms | 24,3 ms |
| Bibliothekssuche (Volltext / alle) | 9,9 / 3,9 ms | 9,8 / 4,0 ms |
| Index öffnen | 0,9 ms | 15,5 ms (erstes Öffnen mit Ergänzung: 315 ms) |

Das Laden der Projektdateien selbst ist nicht enthalten; es bleibt der Hauptanteil bei echter Indexierung.
